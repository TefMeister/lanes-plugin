# The lanes banner

`banner.png` is the finished artwork (2026-09-26), used exactly as delivered. It carries no text
that can go out of date: no version number, no news, no command list. So it is made once and left
alone, and nothing has to be regenerated on a release.

What the plugin is, its commands and how to install it are written on the front page
(`README.md` at the top of this repo) instead, where they are easy to keep true. The smoke test
checks that every command the plugin ships is listed there.

`old-text-banner/` holds the earlier banners and the script that drew text and the version onto
them, kept so any of them can be gone back to. Nothing reads them any more.
